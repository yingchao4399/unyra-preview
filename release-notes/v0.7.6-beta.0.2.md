# Unyra 0.7.6-beta.0.2 · PDF 快速阅读预览版

修复 Windows OCR 组件未随安装包打入导致的识别失败；大型本地 PDF 改为分段读取，优先展示第一页；滚动时只保留可见页与附近页面的画布。新增页码跳转、文档内置目录、单页重试、后台解析进度、暂停/继续识别和系统阅读器入口。

阅读和识别分别排队：先提取内置文字，扫描页使用已有离线 OCR 模型识别，按页缓存。AI 可通过 `api.pdfIndex.list()` 和 `api.pdfIndex.search({ documentId, query, limit })` 查询已经完成的页面，并通过 `api.see` 查看指定页。

## 使用

1. 安装 `Unyra-0.7.6-beta.0.2-Setup.exe`，打开本地 PDF。
2. 顶部输入页码后回车或点击“跳转”，右侧目录支持有内置书签的文档。
3. 扫描件识别需在设置的插件页面启用离线 OCR 并安装模型；阅读器底部有配置入口。已有文字的 PDF 可直接提取文字。
4. 底部显示当前页识别状态和全书进度，可暂停、继续或重试失败页。识别结果保存在本机，重启后逐页复用缓存。

## 预览版范围

- 目前优先支持 Windows Electron 桌面端；本地 PDF 和 OCR 默认在本机处理。
- 云端模型适配、整本书自动摘要、复杂表格结构识别属于后续工作。
- 首屏和远距离跳页耗时受 PDF 页树、图片解码、存储和机器负载影响。此版不能保证所有文档“打开即见”或任意页一秒内显示，详见 [样本实测报告](../docs/pdf-preview-v08-performance.md)。
- 暂停会阻止后续识别，已经进入原生 OCR 的当前一页会完成。整本扫描书仍需逐页识别，AI 搜索只覆盖完成的部分。
- 文档没有内置目录时显示提示，不会自动生成章节目录。字体未嵌入的部分 CJK 文档仍可能缺字；不支持的文档可用系统阅读器打开。
- PDF.js 固定为 6.5.438，包含按需加载的兼容补丁。升级引擎必须同步检查补丁和页面遍历回归测试。
